| 分组 | 数量 | 方法 |
| --- | ---: | --- |
| 规则命中 | 10 | 有意覆盖参数缺失、封装变体、移除和跨表差异 |
| 边界 | 10 | 有意覆盖策略分歧、未知状态、开放结尾、恢复歧义及正常对照 |

## 确认、版本与复现

[human_review.json](human_review.json)保存逐条结论、审核人、日期、确认来源及分析稿SHA256。生成器读取这些明确确认，不自动创造新确认；若分析稿变化，旧确认因哈希不匹配而拒绝沿用。人工文件纳入review_manifest.json校验。

```bash
.venv/bin/python scripts/prepare_review.py
.venv/bin/python scripts/render_review.py
.venv/bin/python -m unittest discover -s tests -v
```

重跑只提取证据、验证来源及重建确认记录，不替代重新审核。目录名review_draft为兼容既有路径保留，当前状态以summary.json和human_review.json为准。历史未确认草稿仅在本地留存，不随当前压缩包提交。

项目整体参与说明见 [项目参与说明](../项目参与说明.md)。累计投入约6小时为提交者估算；扫描秒数与人工时间分开记录。未覆盖完整重放、外部去污染、隐私全面审计及全量语义验收；不从30条选样外推全量指标。
